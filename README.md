# an1me5h.github.io

Personal website of Animesh Hedaoo. Plain HTML, CSS and JavaScript with no build step. It's hosted on GitHub Pages at <https://an1me5h.github.io>.

## Files

- `index.html`: page content (About, Experience, Education, Skills, Contact)
- `data.js`: every timeline entry and project card (add projects and photos here)
- `styles.css`: layout, light and dark themes
- `script.js`: journey timeline, project cards, theme toggle, mobile menu
- `favicon.svg`: browser tab icon

## Edit and publish

1. To add a project, copy an entry in `data.js` and change it. To add photos, put them in `images/` and list them in the entry's `images: [...]`. The first photo becomes the card cover.
2. Edit `index.html` for everything else (each section is marked with a comment such as `<!-- Projects -->`).
2. Preview locally by opening `index.html` in a browser.
3. Commit and push to `main`. GitHub Pages updates within a minute or two.
