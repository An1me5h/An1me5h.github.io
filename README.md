# an1me5h.github.io

Personal website of Animesh Hedaoo. Plain HTML, CSS and JavaScript with no build step. It's hosted on GitHub Pages at <https://an1me5h.github.io>.

## Files

- `index.html`: all page content
- `styles.css`: layout, light and dark themes
- `script.js`: theme toggle, mobile menu, scroll effects
- `favicon.svg`: browser tab icon

## Edit and publish

1. Edit `index.html` (each section is marked with a comment such as `<!-- Projects -->`).
2. Preview locally by opening `index.html` in a browser.
3. Commit and push to `main`. GitHub Pages updates within a minute or two.
